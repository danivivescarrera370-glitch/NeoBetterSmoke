# Neo Better Smoke

An unofficial NeoForge port of the original Fabric "Better Smoke" mod. This port runs natively on NeoForge to prevent rendering pipeline and mixin crashes caused by translation layers like Sinytra Connector.

## 🚀 Features
* **Native Runtime:** Fully compiled for NeoForge, eliminating the need for automated conversion wrappers.
* **Aesthetic Upgrades:** Replaces vanilla flat campfire and smoker particles with smooth, high-density smoke plumes.
* **Wind Dynamics:** Smoke drifts realistically based on real-time weather and environment vectors.
* **Plume Stacking:** Placing campfires next to each other dynamically multiplies particle density for massive cloud effects.

## 🔧 Installation
1. Ensure your launcher profile is running **NeoForge 26.1 / 26.2**.
2. Download the compiled `.jar` file.
3. Drop the file into your profile's `mods` folder.
4. Make sure to remove any Fabric versions of the mod from your directory to prevent runtime conflicts.
